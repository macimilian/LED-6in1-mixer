# LED-6in1-mixer

A mobile-first web app for visually mixing colors on **SHEHDS 7×18W 6-in-1 PAR lights** (RGB + Cold White + Warm White + UV).

## Features
- **Mixer** — individual sliders for all 6 channels with live RGB + DMX readout
- **Palette** — interactive XY color pad with HSL controls, white balance, and UV
- **Presets** — 64 curated presets across 7 categories
- **Saved colors** — unlimited, stored in localStorage
- **PWA** — installable as home screen app on iPhone via Safari

## Install on iPhone
1. Open the GitHub Pages URL in **Safari**
2. Tap the share button **⎙**
3. Select **"Add to Home Screen"**

## Live App
https://macimilian.github.io/LED-6in1-mixer/

## Settings
Adjust how CW, WW and UV channels influence the RGB preview to match your specific fixture's color temperature (defaults: CW 7500K, WW 3200K, UV 395nm).
